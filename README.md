# 📸 拍瞬传 (PaiSnap)

> 局域网内手机拍照，一键传电脑 —— 模拟扫描仪、快速收集照片的最佳工具。

[![Go Version](https://img.shields.io/badge/Go-1.19+-00ADD8?style=flat&logo=go)](https://go.dev/)
[![WeChat Mini Program](https://img.shields.io/badge/微信小程序-2.27.0+-07C160?style=flat&logo=wechat)](https://developers.weixin.qq.com/miniprogram/dev/framework/)

## 📖 项目简介

**拍瞬传** 是一款纯局域网工具，包含 **微信小程序端** 和 **Go 语言服务端**。  
用户可在小程序中调用手机摄像头拍照，照片通过 HTTP 协议上传至同一 WiFi 下的电脑，电脑端自动按标签分类保存，并提供 Web 状态页进行管理和预览。

### 🎯 适用场景

- 📄 家庭、办公室、教育机构内快速将纸质文件扫描成电子档（模拟扫描仪）
- 📸 活动、会议中收集现场照片
- 🛠️ 个人开发者调试图片上传功能
- 🚀 任何需要手机 → 电脑快速传图的场景

## ✨ 功能特性

### 🖥️ 服务端 (Go)

- ✅ 接收图片上传，支持 **标签分组**（自动创建子目录）
- ✅ 实时显示 **已连接的客户端** IP 及活跃时间
- ✅ **二维码** 展示服务地址，手机扫码自动连接
- ✅ 图片管理：**删除** 图片（同时删除磁盘文件）
- ✅ **一键打开** 图片保存目录
- ✅ Web 状态页，**自动刷新**（每 5 秒）
- ✅ 保留最近 **50 张** 图片，按标签分组展示（后上传的在前）
- ✅ 跨平台支持：Windows / macOS / Linux

### 📱 小程序端 (微信小程序)

- ✅ **WiFi 检测**：未连接 WiFi 时无法进入拍照页
- ✅ **扫码连接**：扫描服务端二维码，自动配置地址
- ✅ **手动配置**：支持手动输入服务端 IP + 端口
- ✅ **健康检查**：持续检测服务端状态，断线自动提醒重连
- ✅ **拍照上传**：支持前置/后置摄像头
- ✅ **动态标签**：拍照前可自定义标签，后续上传自动分类
- ✅ **用户引导**：独立的帮助页面，详细说明使用步骤

## 🛠️ 技术栈

| 组件       | 技术                                      |
|-----------|-------------------------------------------|
| 服务端     | Go 1.19+、标准库 `net/http`、`embed`、`html/template` |
| 小程序端   | 微信小程序原生框架、`Camera` API、`wx.uploadFile` |
| 状态页     | HTML5、CSS3、JavaScript、QRCode.js       |
| 打包方式   | Go 编译为单可执行文件，小程序发布至微信后台 |


## 🚀 快速开始

### 1. 启动服务端

#### 方法一：直接运行可执行文件（推荐）

- 从 [Releases](https://github.com/your-repo/paishunchuan/releases) 下载对应系统的二进制文件
- 双击运行（Windows）或终端执行 `./psc-server-xxx`（macOS/Linux）
- 服务会自动打开浏览器状态页，地址为 `http://本机IP:5000/status`

#### 方法二：从源码编译

```bash
cd server
go build -o psc-server main.go
./psc-server

```


### 2. 使用流程

1. 电脑端：确保服务端已运行，防火墙允许 5000 端口

2. 手机端：连接同一 WiFi → 打开小程序 → 扫码或手动输入服务端地址 → 连接成功

3. 拍照：填写标签（如“会议记录”）→ 拍照 → 自动上传

4. 查看：电脑端状态页会实时显示图片，按标签分组排列
