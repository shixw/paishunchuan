❓ 常见问题

手机无法连接服务端？

请按以下顺序排查：

  1. 确保手机与电脑连接同一 WiFi；
  2. 检查电脑防火墙是否放行了程序（首次运行会提示，请允许）；
  3. 确认服务端已正常运行（桌面状态页可见）；
  4. 尝试手动输入IP地址连接。
上传失败怎么办？

上传失败通常与网络或端口有关：

  1. 确认手机WiFi与电脑处于同一网段；
  2. 检查服务端端口（默认5000）未被占用；
  3. 查看电脑端日志文件（状态页可打开日志目录）；
  4. 重启服务端和小程序重试。
如何更新桌面端？

从 GitHub Releases 下载最新版本，替换旧文件即可。图片保存目录（~/拍瞬传图片）不受影响。

数据会上传到云端吗？

不会。 拍瞬传是纯局域网工具，所有照片仅在手机与电脑之间传输，不上传任何云端服务器，您的隐私完全由自己掌控。

支持哪些操作系统？

桌面端支持：

  • Windows 10/11（64位）
  • macOS 10.15+（Intel / Apple Silicon）
  • Linux（Ubuntu/Debian/CentOS 等主流发行版）

小程序端支持 iOS 14+ / Android 7.0+。
